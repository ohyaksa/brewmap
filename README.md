# BREWMAP — 3D Coffee Brewing Studio v1.654

원두·드리퍼·분쇄 설정과 바리스타 프리셋을 구성하고, 투명 드리퍼 기반 3D 추출 애니메이션, 추출 분석, 추출 후 관능평가 기록을 제공하는 정적 웹 앱입니다.

## 배포 파일

GitHub Pages 저장소의 최상위 폴더에 다음 파일을 둡니다.

- `index.html` — 앱 화면 및 반응형 디자인
- `coffee_recipes.js` — 원두·드리퍼·바리스타 프리셋·그라인더 데이터
- `brew_engine.js` — 설정 제어, 레시피·시음 기록 저장/복원, 차트, 3D 추출 타이머 및 사운드
- `help.html` — 사용자 도움말

## 주요 기능

- 드리퍼 → 원두 → 레시피 → 분쇄도 4단계 선택과 선택 전/완료 상태 구분
- Blue Bottle, Hario V60, Kalita Wave 드리퍼별 투명 시각 표현
- 원두 투입량에 따른 커피층 높이 변화, Bloom 최대 팽창, 이후 푸어별 팽창 감소, 배수 시 중앙 함몰 개념 애니메이션
- 원두 선택 후 권장 시작 레시피(원두 중량 입력, 추천 비율·수온·그라인더 모델 기준·목표 시간) 적용 및 전체 잠금, 잠금 해제 후 개인 취향 조절
- 일반 레시피 또는 특별 바리스타 프리셋 선택
- 바리스타 원본의 드리퍼·중량·물량·온도·목표 시간·푸어 일정 적용 및 지정값 잠금
- 바리스타 프리셋의 간략 설명, 원본 설정, YouTube 영상 또는 검색 링크
  - 직접 영상 링크: James Hoffmann, Tetsu Kasuya, Lance Hedrick, George Jinyang Peng, 박준성
  - Scott Rao: 해당 레시피와 일치하는 영상을 단정하지 않고 YouTube 검색 링크 제공
- 등록 그라인더 모델별 눈금 또는 모델을 모를 때 사용하는 정성적 5단계 분쇄도
- 전체/개별 설정 잠금, 슬라이더와 숫자 입력 조절
- 예상 EY/TDS와 실측 EY/TDS 분리 표시
- 세팅 직후 예상 산미·단맛·쓴맛을 한 개의 가로 막대 그래프로 표시(검증된 관능 예측 모델이 아닌 참고 지수)
- SCA 골든컵 참고 영역과 예상/실측 별도 마커
- 추출 완료 후 산미·단맛·쓴맛의 실제 강도(0~5, 0.5 단위)와 예상 강도를 비교하고 브라우저 자동 저장
- 전체 커피 만족도는 별표 5점 만점, 반별점(0.5점) 단위로 별도 평가
- 재추출 의향(다시 추출 / 수정 후 재추출 / 재추출하지 않음)과 개인 메모 저장
- 재사용 레시피 설정은 사용자가 직접 저장하며, 저장 시 해당 세션의 관능평가를 연결
- 분석 표시 순서: 예상 EY/TDS → 예상 향미 막대 그래프 → 시간별 용출 개념도/목표 시간선 → SCA 골든컵 차트 → 추출 프로파일·푸어 일정·비율 통계 → 추출 시작 버튼
- 3D 추출 화면: 비이커 중앙에 대기 남은 시간, 왼쪽에 현재/총 물 투입량, 오른쪽에 경과/목표 시간을 표시
- 푸어 중 실제 표시 물량은 프로그램 스케줄에 따른 누적 목표 진행값이며 실측 저울 데이터가 아님
- 3D 추출 가이드, 타이머, 음성 안내 및 물 붓기 사운드
- 레시피 보관함, CSV 저장/백업/복원

## 예상값과 실측값 해석

예상 TDS와 EY는 수온·시간·물:원두 비율·일반 분쇄 단계 등을 반영한 **화면용 단순 휴리스틱**입니다. 실험 데이터로 보정·검증된 개인별 추출 예측 모델이 아닙니다. 예상 EY의 ±1.8%p 및 예상 TDS의 ±0.15%p 표시는 참고 폭일 뿐 통계적 신뢰구간이 아니며, 실제 측정 결과와 다를 수 있습니다.

SCA 차트의 음영 영역은 참고 기준 TDS 1.15–1.35%, EY 18–22%를 나타냅니다. 예상값은 파란 사각형, 실측값은 빨간 원형으로 구분합니다.

실측 EY는 굴절계 TDS와 실제 완성 음료 무게가 모두 입력된 경우에 계산합니다.

`EY(%) = 측정 TDS(%) × 실제 완성 음료 무게(g) ÷ 원두량(g)`

## 3D 커피층 애니메이션의 범위

드리퍼별 내부 형태와 원두량에 따른 커피층 높이를 시각적으로 표현합니다. 뜸 들이기 때 가장 크게 부풀고, 1·2·3차 푸어가 진행될수록 팽창 폭이 작아지며, 배수 중에는 커피층 높이가 낮아지고 중앙이 가장자리보다 더 깊게 들어가도록 구성했습니다. 이는 추출 과정을 이해하기 위한 개념 애니메이션이며 실제 커피층의 유체·가스 거동을 물리적으로 검증한 시뮬레이션은 아닙니다.

## 추출 평가와 레시피 저장

추출 완료 후 사용자는 산미·단맛·쓴맛의 강도를 각각 0~5(0.5 단위)로 입력합니다. 이는 맛의 강도이지 좋고 나쁨을 나타내는 별점이 아닙니다. 전체 커피 만족도는 별도로 5점 만점의 별점으로 평가하며 0.5점 단위(예: 4.5점)를 지원합니다. 재추출 의향과 개인 메모도 기록할 수 있습니다. 평가 입력은 현재 브라우저의 `localStorage`에 자동 저장되며, [평가 완료]를 누르면 기록 상태가 완료로 표시됩니다.

재사용할 레시피 설정은 사용자가 [설정값 저장]을 직접 눌러 보관함에 저장합니다. 같은 추출 세션에서 관능평가를 저장했다면 그 평가도 레시피와 연결합니다. 저장된 추출 기록과 레시피는 현재 브라우저에 국한되며 서버로 자동 전송되지 않습니다.

## 설치 / 업데이트

1. 현재 GitHub 저장소의 기존 파일을 먼저 백업합니다.
2. `index.html`, `coffee_recipes.js`, `brew_engine.js`, `help.html`을 저장소 최상위 폴더에 업로드해 기존 파일과 교체합니다.
3. `README.md`도 저장소 문서로 사용하려면 함께 업데이트합니다.
4. GitHub Pages 배포가 끝나면 브라우저에서 강력 새로고침합니다 (`Ctrl + F5`).
5. `Settings → Pages`에서 배포 소스가 `main` 브랜치와 `/ (root)`인지 확인합니다.

## 데이터와 브라우저 저장

레시피와 추출 시음 기록은 기본적으로 해당 브라우저의 `localStorage`에 저장됩니다. 브라우저 데이터 삭제 또는 다른 브라우저/기기로 이동하면 자동 공유되지 않으므로 CSV 백업을 권장합니다.

## 마스터 인증의 현재 제한

10일 마스터 세션은 현재 동일 브라우저의 `localStorage`에서 유지됩니다. **같은 물리적 기기의 Chrome·Edge 등 서로 다른 브라우저 간 인증 공유는 정적 GitHub Pages만으로 구현할 수 없습니다.** 기기 간/브라우저 간 인증을 구현하려면 서버 측 인증과 기기 등록 설계가 필요합니다. 따라서 이 버전은 동일 브라우저 10일 유지까지만 제공합니다.

## 분쇄 설정 원칙

등록 그라인더 숫자는 해당 모델의 고유 눈금으로만 사용합니다. 일반 5단계는 정성적 분류이며 마이크론 또는 다른 그라인더의 눈금으로 환산하지 않습니다. Feima 600N의 사용자 확인값 4.5, Baratza Encore Original의 사용자 확인값 14를 보존합니다. 과거 v1.5의 `grind` 값은 시뮬레이션 저항지수였으므로 실제 그라인더 눈금으로 해석하지 않습니다.
