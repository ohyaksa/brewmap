# BREWMAP — 오찬욱 바리스타 3D 브루잉 다이얼러 v1.651

원두·드리퍼·분쇄 설정과 바리스타 레시피를 구성하고, 3D 추출 가이드와 브루잉 분석을 확인하는 정적 웹 앱입니다.

## 배포 파일

GitHub Pages 저장소의 최상위 폴더에 다음 파일을 둡니다.

- `index.html` — 앱 화면 및 반응형 디자인
- `coffee_recipes.js` — 원두·드리퍼·바리스타 프리셋·그라인더 데이터
- `brew_engine.js` — 설정 제어, 레시피 저장/복원, 차트, 3D 추출 타이머 및 사운드
- `help.html` — 사용자 도움말

## 주요 기능

- 드리퍼 → 원두 → 레시피 → 분쇄도 4단계 설정 메뉴를 상시 표시하고 순서에 따라 입력 활성화
- 일반 레시피 또는 특별 바리스타 프리셋 선택
- 바리스타 원본의 드리퍼·중량·물량·온도·목표 시간·푸어 일정 적용 및 지정값 잠금
- 등록 그라인더 모델별 눈금 또는 그라인더 모델을 모를 때 사용하는 정성적 5단계 분쇄도
- 전체/개별 설정 잠금, 슬라이더와 숫자 입력 조절
- 산미·단맛·쓴맛의 사용자 관능 평가 그래프
- 시간별 성분 용출 개념도와 목표 시간선
- 프로그램 푸어 일정 누적 물량 그래프 및 단계별 표
- 물:원두 추출 비율 비교 그래프와 추출 프로파일 통계
- SCA 골든컵 참고 영역 및 사용자 실측 TDS/EY 표시
- 3D 추출 가이드, 타이머, 음성 안내 및 물 붓기 사운드
- 레시피 보관함, CSV 저장/백업/복원
- 추출 완료 시 방금 사용한 레시피 저장 여부 확인

## 수율 및 농도 데이터 해석

SCA 목표 참고 범위와 실제 측정값을 구분합니다. 실측 EY는 굴절계로 측정한 TDS와 실제 완성 음료 무게가 모두 입력된 경우에만 계산합니다.

`EY(%) = TDS(%) × 실제 완성 음료 무게(g) ÷ 원두량(g)`

SCA 차트의 참고 범위는 TDS 1.15–1.35%, EY 18–22%로 표시합니다. 산미·단맛·쓴맛은 사용자가 시음 후 입력하는 평가값이며, 레시피 설정만으로 자동 예측하지 않습니다. 시간별 성분 용출 곡선은 실험 데이터가 아닌 설명용 개념도입니다.

## 설치 / 업데이트

1. 현재 GitHub 저장소의 기존 파일을 먼저 백업합니다.
2. 위 4개 배포 파일을 저장소 최상위 폴더에 업로드해 기존 파일과 교체합니다.
3. GitHub Pages 배포가 끝나면 브라우저에서 강력 새로고침합니다 (`Ctrl + F5`).
4. `Settings → Pages`에서 배포 소스가 `main` 브랜치와 `/ (root)`인지 확인합니다.

## 데이터와 브라우저 저장

레시피는 기본적으로 해당 브라우저의 `localStorage`에 저장됩니다. 브라우저 데이터 삭제 또는 다른 브라우저/기기로 이동하면 자동 공유되지 않으므로 CSV 백업을 권장합니다.

## 마스터 인증의 현재 제한

10일 마스터 세션은 현재 동일 브라우저의 `localStorage`에서 유지됩니다. **같은 물리적 기기의 Chrome·Edge 등 서로 다른 브라우저 간 인증 공유는 정적 GitHub Pages만으로 구현할 수 없습니다.** 기기 간/브라우저 간 인증을 구현하려면 서버 측 인증과 기기 등록 설계가 필요합니다. 따라서 이 버전은 동일 브라우저 10일 유지까지만 제공하며, 크로스 브라우저 인증은 별도 백엔드 연동 과제입니다.

## 분쇄 설정 원칙

등록 그라인더 숫자는 해당 모델의 고유 눈금으로만 사용합니다. 일반 5단계는 정성적 분류이며 마이크론 또는 다른 그라인더의 눈금으로 환산하지 않습니다. 과거 v1.5의 `grind` 값은 시뮬레이션 저항지수였으므로 실제 그라인더 눈금으로 해석하지 않습니다.
