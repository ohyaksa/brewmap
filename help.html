3. v1.6 세팅 조작 가이드 (막대 조절 · 숫자 직접 입력 · 🔒 고정) 1줄 2개 컴팩트 배치로 스크롤 최소화

슬라이더 막대만으로는 세밀한 숫자를 맞추기 어렵고 손가락이 미끄러지는 문제를 해결하기 위해, 막대는 큼직한 단위로 움직이고 숫자 입력칸과 [-] [+] 버튼은 세밀한 단위로 작동하도록 이원화했습니다.

조절 항목 조작 방식 입력 가능 범위 / 선택값 🔒 고정 잠금 효과
1. 원두량 (g) 막대 5g 단위 · 직접 입력 0.5g · 버튼 ±1g 10g ~ 60g 잠금 시 원두량 고정 (중량 프리셋 변경 시에도 보호)
2. 총 물 투입량 (g) 막대 20g 단위 · 직접 입력 1g · 버튼 ±5g 120g ~ 1000g 잠금 시 물 투입량 고정
3. 추출 수온 (°C) 막대 1°C 단위 · 직접 입력 0.1°C · 버튼 ±0.5°C 80.0°C ~ 100.0°C 잠금 시 원두를 바꿔도 수온 유지
4. 목표 시간 (초) 막대 15초 단위 · 직접 입력 1초 · 버튼 ±5초 60초 ~ 360초 잠금 시 목표 추출 시간 고정
5. 분쇄 설정 아래 3가지 방식 중 하나 선택 등록 그라인더 모델·눈금 / 일반 분쇄도 1~5단계 / 설정 안 함 잠금 시 현재 선택 방식과 해당 값 고정
⑤ 분쇄 설정 — 세 가지 방식 중 하나만 선택:
  1. 등록된 그라인더 모델 및 눈금: 기존 그라인더 13종에서 모델을 선택하고 해당 기기의 고유 눈금을 기록합니다. 약국 Feima 600N의 사용자 실사용 기준은 4.5, 가정용 Baratza Encore Original의 기준은 14입니다.
  2. 일반 분쇄도 5단계: 1단계 매우 굵게 → 2단계 굵게 → 3단계 중간(기본값) → 4단계 곱게 → 5단계 매우 곱게. 모델을 모르는 사용자를 위한 정성적 분류입니다.
  3. 분쇄 설정 안 함: 분쇄 관련 입력 없이도 레시피 작성, 저장 및 추출 진행이 가능합니다.
세 방식은 서로 배타적이며 선택한 방식의 입력창만 표시됩니다. 일반 분쇄도 5단계를 서로 다른 그라인더의 숫자 눈금이나 마이크론(μm)으로 환산하지 않습니다.
🔒 세팅 고정(Lock) 활용 팁: 필요한 설정을 맞춘 뒤 각 박스의 [🔓 고정] 버튼을 누르면 해당 입력이 잠깁니다. 우측 상단의 [🔓 전체 세팅 고정하기]는 원두량·물 투입량·수온·목표 시간·분쇄 설정을 함께 잠급니다. 분쇄 설정 안 함을 선택하면 분쇄 잠금 버튼은 표시되지 않습니다.

4.1 원두 중량 7단계 × 4가지 추출 모드 물 투입량 검증표

아래 표의 모든 수치는 완성된 커피 음료의 무게가 아니라 드리퍼 및 서버에 붓는 총 물 투입량(g)입니다. 원두와 필터가 물을 흡수하므로 실제 서버에 모이는 완성 음료 무게는 투입수량보다 적습니다.

💡 바이패스(Bypass) 모드 주의사항: 바이패스는 농축 추출(1:12) 후 깨끗한 온수(1:4)를 가수해 농도를 조절하는 방식입니다. 특정 좋은 성분만 선택적으로 추출하거나 떫은맛을 원천 차단하는 기법이 아니며, 40~50g 대용량 추출 시에는 드리퍼 용량을 확인하거나 두 번에 나누어 추출하세요.

📊 차트 2종 & 실측 TDS/EY 계산

  • SCA 골든컵 기준: 전통적인 SCAA/SCA 골든컵 목표 영역은 농도(TDS) 1.15~1.35%, 추출수율(EY) 18.0~22.0%입니다. (기준 PDF | 차트 수식)
  • 실측 공식: EY(%) = TDS(%) × 실제 완성 음료 무게(g) ÷ 원두량(g)
  • 굴절계 측정 TDS와 실제 완성 음료 무게가 모두 입력된 경우에만 EY를 계산합니다. 미측정 상태에서는 EY/TDS 추정값이나 차트 위치를 표시하지 않습니다.
