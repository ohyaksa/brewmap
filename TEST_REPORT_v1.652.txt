5. 확인이 필요한 제한
- 실제 Chromium 브라우저에서의 통합/시각 검증은 실행 환경의 브라우저 접근 제한으로 완료하지 못함. 따라서 위 결과는 정적 검사 및 Node VM 로직 테스트 결과이며 실제 GitHub Pages 배포 검증이 아님.
- 예상 EY/TDS는 실험 자료로 보정된 추출 예측 모델이 아니라 단순 휴리스틱임. 참고값으로만 사용하고 실제 측정과 구분해야 함.
- 3D 커피층 팽창/중앙 함몰은 레시피 단계 기반 개념 애니메이션이며 유체·가스 거동의 물리 시뮬레이션이 아님.
- 마스터 10일 인증은 동일 브라우저의 localStorage 기준. 물리적 기기의 서로 다른 브라우저 간 인증 공유는 서버 인증/기기 등록 기능 없이는 구현되지 않음.
- 추출/관능평가 자동 저장은 현재 브라우저 localStorage에 저장되며 서버로 전송되지 않음.
