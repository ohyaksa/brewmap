4. 브라우저 통합 확인의 한계
- 테스트 환경에서 Chromium을 실행하려 했으나, 로컬 파일 및 localhost 페이지 접근이 실행 환경 정책에 의해 차단되어 실제 브라우저 화면·마우스 상호작용 테스트를 완료하지 못함.
- 따라서 위 Canvas 렌더링은 브라우저 UI가 아닌 Mock Canvas 컨텍스트에서 함수 예외 여부를 확인한 테스트임.
- GitHub Pages에 배포한 실제 Chrome/Edge 화면, 애니메이션 프레임, 음성·사운드 출력은 사용자가 배포 후 확인해야 함.

5. 저장 및 운영 범위
- 추출 평가 기록은 현재 브라우저 localStorage에 자동 저장함.
- 사용자가 별도로 저장을 요청한 레시피에는 해당 세션의 평가 정보를 함께 연결함.
- Firebase 또는 서버 저장 및 기기 간 자동 동기화는 v1.654에 포함하지 않음.
- 예상 TDS/EY 및 향미 지수는 실험으로 보정된 예측 모델이 아니라 참고용 휴리스틱으로 표시함.
