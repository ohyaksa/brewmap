BREWMAP v1.653 — 테스트 결과 보고서
테스트 일자: 2026-10-30

1. 변경 범위
- 세팅 조절 패널과 추출 분석 패널을 세로 단일 컬럼으로 배치.
- 예상 EY/TDS 다음에 예상 산미·단맛·쓴맛 단일 가로 막대 그래프 배치.
- 시간별 성분 용출 개념도 및 목표 시간선 다음에 SCA 골든컵 차트를 세로 순서로 배치.
- 기존 추출 프로파일, 푸어 일정, 추출 비율 통계 이후 추출 시작 버튼과 설정값 저장 버튼 배치.
- 헤더의 기존 즉시 추출 버튼은 최종 추출 시작 버튼 위치로 스크롤하는 탐색 버튼으로 변경.
- 실제 시음 평가 그래프는 추출 완료 후 평가 패널 안으로 이동.
- 3D 캔버스 중앙에 대기 남은 시간, 왼쪽에 현재/총 물 투입량, 오른쪽에 경과/목표 시간 표시.
- 데이터 파일(coffee_recipes.js)은 변경하지 않음.

2. 정적 검사
- brew_engine.js: node --check 통과.
- coffee_recipes.js: node --check 통과.
- index.html: BeautifulSoup 파싱 통과.
- HTML ID 157개, 중복 ID 없음.
- 버전 배지: v1.653 확인.
- 분석 요소 DOM 순서: 예상 EY → 예상 향미 그래프 → 시간 용출 그래프 → SCA 차트 → 추출 통계 → 최종 추출 시작 버튼 확인.
- 관능평가용 flavorChart가 추출 후 모달 안에 하나만 존재.

3. Node VM 모의 로직 테스트
- 예상 향미 경향 함수가 산미·단맛·쓴맛 각 0.5~4.8 범위 내 지수를 산출.
- 예상 향미 캔버스 그래프 라벨 렌더 호출 확인.
- Blue Bottle, Hario V60, Kalita Wave 각각에 대해 pouring / waiting / done 상태 draw3DScene 호출 성공.
- 비이커 중앙 대기 카운트다운 문자열, 좌측 현재 물 투입량, 우측 경과 시간 표시 호출 확인.
- 예시 입력 30g 원두 / 420g 물 / 95°C / 210초 / 일반 분쇄 3단계에서 참고 지수: 산미 2.88, 단맛 3.21, 쓴맛 2.61.

4. 예측값 해석 주의
- 산미·단맛·쓴맛 값은 사용자 요청에 따라 추가한 파라미터 기반 화면용 휴리스틱 지수이며, 실험으로 보정된 관능 예측 모델이 아님.
- 예상 EY/TDS 역시 기존의 실험 미검증 휴리스틱이며, 실제 관능·굴절계 측정 결과와 다를 수 있음.
- 3D 물량은 프로그램 푸어 스케줄로 계산한 누적값이며 실제 저울 센서 입력이 아님.
- 중앙 대기 시간과 오른쪽 시간은 프로그램 타이머 기준이며 실측 장비 타이머와 동기화되지 않음.

5. 브라우저 통합 검증 제한
- Chromium headless가 실행 환경에서 반복 시간 초과되어 실제 브라우저 스크린샷 및 클릭 통합 검증은 완료하지 못함.
- 따라서 정적 검사 및 Node VM 모의 로직 검증까지 완료한 상태이며, GitHub Pages에 업로드한 뒤 실제 PC/모바일 브라우저에서 최종 UI와 상호작용 확인이 필요함.
